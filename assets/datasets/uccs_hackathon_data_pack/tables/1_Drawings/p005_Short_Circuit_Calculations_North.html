Short-Circuit Calculations
The following calculations are based on the "Point-by Point" method where:
f = 1.732 x L x I / C x E
M = 1 / (1+f)
Isc = Isc x M
XFMR: f = (IP(sca) x Vp x %Z) / (100,000 x KVA)
IS(sca) = (Vp x M x IP(sca)) / Vs
